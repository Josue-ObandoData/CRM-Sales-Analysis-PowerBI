# 📊 Sales Performance & CRM Analysis (Power BI)

## 🎯 Objetivo del Proyecto
Analizar más de 8,000 registros de un sistema CRM para identificar cuellos de botella en las ventas y el desempeño de los agentes, facilitando la toma de decisiones estratégicas.

## 🛠️ Tecnologías Utilizadas
* **Power BI / Power Query**
* **DAX** (Medidas avanzadas y optimización)
* **Modelado de Datos** (Esquema Estrella)
* **UI Design** (PowerPoint para layouts personalizados)
